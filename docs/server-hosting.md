# Игровой сервер на Render

Сервер в этом репозитории уже поддерживает комнаты на двоих, приглашения,
синхронизацию персонажей, физику и переподключение. `render.yaml` запускает
его через существующий Dockerfile. HTTPS и WebSocket предоставляет Render.

## Разместить сервер

1. Откройте [Deploy to Render](https://render.com/deploy?repo=https://github.com/dmsznv-dot/cozygame).
2. Войдите в свой аккаунт Render. Если потребуется, подключите GitHub и разрешите доступ к `dmsznv-dot/cozygame`.
3. Проверьте создаваемый сервис `cozygame-server`: в конфигурации выбран бесплатный план `free`. Подтвердите создание Blueprint.
4. Дождитесь статуса **Live**. Скопируйте фактический HTTPS-адрес из панели сервиса: Render может добавить суффикс к имени.
5. Откройте `<адрес-сервера>/health`. Ответ должен содержать `"ok":true`.

По адресу сервиса доступна и сама игра: можно сразу создать прогулку и
отправить ссылку второму игроку. Домен Render пока не создан; ссылка выше
открывает настройку размещения, а не готовый сервер.

## Подключить страницу GitHub Pages

1. В [настройках переменных GitHub Actions](https://github.com/dmsznv-dot/cozygame/settings/variables/actions)
   создайте переменную **GAME_SERVER_URL**. Значение — HTTPS-адрес из Render,
   без `/socket` и `/health`.
2. Откройте [Publish GitHub Pages](https://github.com/dmsznv-dot/cozygame/actions/workflows/pages.yml)
   и выберите **Run workflow** для `main`.
3. После завершения публикации обновите [игру](https://dmsznv-dot.github.io/cozygame/).
   «Начать прогулку» создаст сетевую комнату. Кнопка «Пригласить» скопирует
   ссылку для второго игрока. «Прогуляться одному» останется доступна отдельно.

Адрес сервера публичный; это переменная, а не пароль. Не передавайте токены
Render или GitHub через чат.

## Особенности бесплатного тарифа

- По [правилам Render](https://render.com/docs/free), сервис засыпает после
  15 минут без входящего трафика. Пробуждение занимает около минуты.
  Перед первой совместной прогулкой откройте `/health` и дождитесь ответа.
  Если игра уже показала ошибку подключения, повторите запуск после пробуждения.
- Комнаты и прогресс хранятся в памяти: при перезапуске, засыпании или обновлении
  сервиса они исчезнут. Создайте новую комнату после перезапуска.
- Используйте один экземпляр сервера: комнаты разных экземпляров не разделяют память.
- Платный постоянно работающий тариф можно выбрать позже в Render; эта конфигурация его не включает.

## Проверка локально

```sh
npm ci
npm run build
npm start
# В другом терминале:
node tests/socket-check.mjs
```

Проверка соединяет два клиента, проверяет синхронизацию, ограничение комнаты
двумя участниками, изоляцию комнат и восстановление подключения.
