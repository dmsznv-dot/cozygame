# Тихая тропа — первая версия
Согласовано: браузерная игра на двоих, лес, три загадки, приглашение, окраска круглых персонажей, прыжки, броски, звук и мягкий свет. Общение через внешний звонок.
Three.js/TypeScript/Vite, Node WebSocket server, Rapier для серверных бросков. Процедурные оригинальные модели. Максимум два игрока, секрет восстановления в sessionStorage. Комнаты сохраняются в памяти до перезапуска, удаляются после 30 минут простоя.
Знаки: один стоит на плите в домике, другой вводит последовательность рисунков. Броски: один управляет корзиной, другой бросает три шара. Лампы: один наблюдает число огней на плите, другой вводит код по таблице. Для каждой задачи нужны два различных игрока. Три решения открывают мост к финальной поляне.
Проверки: две браузерные сессии, предел комнаты, reconnect, невалидные данные, изоляция, невозможность одиночного решения, физика бросков, WebGL скриншоты, управление и сборка.
