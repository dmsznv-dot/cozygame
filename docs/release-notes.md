# Тихая тропа 0.1 — 6 октября 2026

Первая играбельная лесная глава для двух игроков в браузере. В проекте есть исходники, готовая клиентская сборка, сервер комнат, Dockerfile и инструкция запуска.

Реализованы три совместные задачи, приглашения, выбор цвета, движение от первого лица, прыжки, поднятие и броски шаров, указатель, общие состояния, автоматическое восстановление соединения. Оформление: оригинальная процедурная сцена, ветер в кронах, вода, туман и мягкие тени. Звук синтезируется в браузере.

Исправления по результатам проверки:
- Согласованы проверки столкновений игрока и сервера у углов зданий; отклонённое движение возвращает игрока к серверной позиции.
- Повторный захват мыши работает после первого отказа браузера; Esc открывает меню независимо от события потери захвата.
- Отброшен первый скачок координат мыши после захвата, чтобы камера не улетала в небо.
- Шрифты включены в проект; внешние обращения к Google Fonts не требуются.
- Команда npm start работает без платформозависимого присваивания NODE_ENV.

Публичного размещения нет. Для разных сетей нужен постоянно работающий Node.js/Docker-сервер с WebSocket и HTTPS. В домашней сети оба игрока используют IP компьютера с запущенным сервером. Комнаты хранятся в оперативной памяти до перезапуска. Подробные ограничения и команды — в README.md.

## GitHub Pages
Исходники подготовлены для репозитория dmsznv-dot/cozygame. Автоматическая сборка и публикация клиента выполняются GitHub Actions. Файлы и шрифты поддерживают подпапку /cozygame/. Настройка GAME_SERVER_URL связывает Pages с отдельным игровым сервером. Без неё доступен честно обозначенный предпросмотр; создание и вход в комнаты отключены. Добавлены 5 тестов выбора адреса подключения и браузерная проверка статического размещения.
