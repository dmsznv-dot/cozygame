# Тихая тропа
Уютная браузерная 3D-прогулка от первого лица для двоих. Первая лесная глава: домик со знаками, совместные броски в корзину, лампы и коды. Решите три задачи, чтобы открыть мост к финальной поляне.

## GitHub Pages и игровой сервер

**Первое включение:** откройте [Settings → Pages](https://github.com/dmsznv-dot/cozygame/settings/pages), выберите **Source: GitHub Actions**, затем [Actions → Publish GitHub Pages](https://github.com/dmsznv-dot/cozygame/actions/workflows/pages.yml) → **Run workflow**. Интеграции не хватило прав включить Pages самостоятельно (HTTP 403). Пока Pages выключен, workflow успешно собирает клиент и сохраняет артефакт, а публикацию пропускает с пояснением.


GitHub Pages публикует **только браузерную часть**. Node.js/WebSocket и комнаты на нём не запускаются. Без отдельного сервера опубликована сцена-предпросмотр с выбором цвета; кнопки совместной игры отключены с объяснением.

Workflow `.github/workflows/pages.yml` проверяет код, собирает клиент и публикует его в Pages после push в `main`. Готовую сборку можно скачать в артефактах Actions (`github-pages`). Исходники и lockfile хранятся в Git; `node_modules` и локальный `dist` не коммитятся.

Чтобы включить совместную игру:
1. Разместите этот же репозиторий на Node.js/Docker-хостинге. Команды: `npm ci && npm run build`, затем `npm start`. Сервер должен предоставлять HTTPS/WSS и поддерживать долгие WebSocket-соединения.
2. В репозитории откройте **Settings → Secrets and variables → Actions → Variables** и создайте `GAME_SERVER_URL` со значением HTTPS-адреса сервера (например, `https://game.example.com`). Это публичный адрес, не секрет.
3. Запустите **Actions → Publish GitHub Pages → Run workflow**. После новой публикации кнопки создания и входа в комнату станут доступны.

У Pages и игрового сервера разные адреса; ссылки-приглашения остаются на Pages, а соединения идут к игровому серверу. Вход через OpenAI здесь пока **не реализован** — GitHub Pages сам по себе его не предоставляет.

## Запуск
Нужен Node.js 22.12+ (проверено на 24).
```sh
npm ci
npm run build
npm start
```
Откройте http://localhost:3000. Для разработки: `npm run dev`.

На двух компьютерах в одной Wi-Fi сети: запустите сервер на одном, откройте на обоих `http://IP-КОМПЬЮТЕРА:3000`, разрешив входящие подключения к порту 3000. Создайте комнату, передайте ссылку или код другу. Ссылка с `localhost` работает только на компьютере, где запущен сервер.

Для игры через интернет разместите весь проект на сервере с Node.js/Docker и поддержкой WebSocket, подключите HTTPS. Статический хостинг не подходит: нужен сервер комнат. Docker: `docker build -t quiet-trail .`, затем `docker run --rm -p 3000:3000 quiet-trail`. Переменная `PORT` задаёт порт. `/health` — проверка доступности. Публичное размещение в этой версии не настроено.

## Управление
- WASD — движение; мышь — обзор; Shift — быстрее.
- Пробел — прыжок; E — поднять шар / рычаг; ЛКМ или E с шаром — бросить.
- Q (удерживать) — показать направление другу.
- 1–4 — рисунки у панели; 1–9 — код у ламп; ← → — корзина, пока держите рычаг.
- Esc — меню, звук и качество; при возврате нажмите кнопку для захвата мыши.

## Загадки
**Знаки:** один стоит на плите в домике, второй вводит показанную ему последовательность на внешней панели. Неправильный рисунок сбрасывает ввод.
**Броски:** один держит рычаг и управляет корзиной; другой берёт шар у подставки. С круга в центре площадки цельтесь немного выше края корзины. Нужно три попадания. Промахнувшийся шар возвращается через девять секунд.
**Светлячки:** один стоит на плите и считает светящиеся лампы. Другой с другой стороны стены переводит количество в код по таблице. Три раунда.

## Что уже работает
- До двух игроков в каждой независимой комнате; случайный код и ссылка приглашения.
- Синхронизация персонажей, жеста-указателя, шаров, корзины, огней и прогресса.
- Серверная физика шаров Rapier, проверка совместных действий, ограничения движения.
- Восстановление своего места при обновлении той же вкладки; автоматическое переподключение при потере сети.
- Круглые персонажи, выбор цвета; процедурный лес, туман, мягкие тени, ветер в кронах, водный шейдер.
- Синтезированные ветер, птицы, шум воды, шаги и звуки успеха. Нет внешних звуковых зависимостей.

## Ограничения первой версии
- Комнаты и прогресс в памяти: живут до перезапуска сервера; пустые комнаты очищаются через 30 минут. Места заняты участниками до удаления комнаты. В новой вкладке без sessionStorage место не восстанавливается.
- Голосового чата нет — используйте внешний звонок. Игра рассчитана на компьютеры с мышью, клавиатурой и WebGL 2; мобильное управление не реализовано.
- Геометрия мира плоская и стилизованная. Физика шаров учитывает землю и попадание в корзину, но пока не все декоративные предметы. Игроки сталкиваются со стенами, стволами и границами реки; скамейки и декорации не блокируют путь.
- Нет долговременных сохранений, аккаунтов и защиты от целенаправленного читерства. Это развиваемый кооперативный прототип для небольшой компании.

## Структура для обновлений
- `shared/game.ts` — станции, коллизии, общий протокол и настройки задач.
- `server/rooms.ts` — игроки, правила, авторитетная физика, прогресс.
- `server/index.ts` — HTTP/WebSocket, комнаты и лимиты сообщений.
- `src/world.ts` — лес, освещение, модели и шейдеры.
- `src/avatar.ts` — персонажи; `src/audio.ts` — звук.
- `src/main.ts` — управление, сеть и UI; `src/style.css` — интерфейс.

## Ресурсы
Модели, интерфейс и звук созданы процедурно для проекта. Шрифты Manrope и Prata — Google Fonts, лицензия OFL; файлы и лицензии лежат в `src/assets/fonts`. Big Walk использован как референс кооперативного общения; его графика, звук и код не используются.
